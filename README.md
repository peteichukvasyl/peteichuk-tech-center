# Peteichuk Anonymous Chat

## Запуск

Потрібен Node.js.

```bash
cd ~/projects/peteichuk-workspace
node server.js
```

Відкрийте http://localhost:3000

## Реєстрація

Введіть ім'я та пароль від 6 до 100 символів. Після реєстрації сервер створює ID, зберігає сcrypt-хеш пароля та автоматично створює сесію.

Для наступного входу потрібні тільки ID + пароль. Ім'я для входу не використовується.

## Повідомлення

Користувачі бачать ім'я та текст повідомлення. Власник може редагувати або видаляти власні повідомлення. Повідомлення автоматично видаляються після 24 годин.

## Дані

Користувачі: data/users.json
Повідомлення: data/messages.json

Це невеликий Node.js-проєкт. Для публічного production-сайту варто додати базу даних, rate limiting, CSRF-захист, резервні копії та HTTPS.
